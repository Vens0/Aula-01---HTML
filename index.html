Tag b

A tag b será usada por destacar o texto em negrito.

Exemplo em negrito

Tag code

A tag code é utilizada para formatar o texto em letra de código.

Código código código

Tag mark

Tag responsável por destacar um texto.

Texto marcado

Tag q

Tag que adiciona aspas para uma citação curta.

Citação curta

Tag s

A tag adiciona um risco no texto afim de determinar que não é mais relevante.

Não é relevante

Tag strong

Tag utilizada para indicar importância. Geralmente está em negrito.

Importante

Tag var

Utilizada para representar uma variável. Geralmente está em itálico.

x y z

Tag small

Utilizado para representar comentários ou apenas letras menores. Sua fonte é menor.

Comentário pequeno

Tag em

Utilizada para indicar ênfase. Pode ser aninhada caso seja necessário aumentar a ênfase.

Ênfase para frase

Tag cite

A tag cite é utilizada para indicar o título de uma obra criativa.

Título

Tag abbr

Utilizado para abreviar palavras.

p. ex

Tag u

Utilizado para sublinhar palavras, na maioria das vezes para indicar erros ortográficos.

GitRub

Tag br

Insere uma quebra de linha. Recomendado para escrever poemas ou discursos.

Poema legal


Legal poema

Tag adress

Usado para determinar quais são as informações do autor, como o e-mail, URL ou telefone. É escrito em itálico.

henrique_venso@estudante.sesisenai.org.br

Tag button

Utilizado para definir um botão clicável.

Utilizado para adicionar links clicáveis.

Tag ins

Utilizada para determinar um trecho que foi adicionado ao texto. Geralmente utilizada em conjunto com a tag del.

Tag del

Usada para representar um texto que foi excluído, representado por um tachado.

Bom dia
